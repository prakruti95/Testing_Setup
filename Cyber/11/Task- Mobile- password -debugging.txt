Task:- Mobile password unlocking.
Method:- usb debugging-(Brute force attack)
Requirement:- usb cable(to provide connection between both devices)
            - the mobile device's usb debugging option should be turned on(in developers option)
Tool:- CiLocks(get it from git)
Git link:- https://github.com/tegal1337/CiLocks.git 
Meaning of brute force:- it means to try each and every combinations until the lock opens.
		      eg-if we are doing 4-pin attack then it would tre 0000 to 9999 till it opens.
steps:- first you should check weather device is connected on kali if you are using kali in VMware.
      - open your Linux terminal and git clone the tool which is a external tool.
      - then to get in to the tool by 'cd CiLocks'.
      - then 'sudo bash cilocks'(to get into the tool)
      - tool contains- [01] Update CiLocks
 		       [02] Bruteforce 4-Digit PIN
 		       [03] Bruteforce 6-Digit PIN
 		       [04] Wordlist Lockscreens
 		       [05] Bypass Lockscreens
 		       [06] Root Android Device
 		       [07] ADB Toolkit
 		       [08] Reset Data
 		       [09] Remove Lockscreen (Root Required)
 		       [10] Jump into Metasploit
 		       [11] Scrcpy (Device Control)
 		       [12] Get Phone Information
		       [13] IP Logger (Over Internet)
 		       [14] GetCam (Webcam Capture)
 		       [15] Firestore Vulnerability Checker
 		       [99] Exit
      - we are doing 4-pin brute force attack so we need to press '2' on keypad.
      - the attack would successfully start.
